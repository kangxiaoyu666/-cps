# 开发规范

## 后端

- 按 `controller/application/domain/repository/integration` 分层；Controller 不承载资金计算和事务。
- 业务实体不直接作为 DTO；所有输入使用 Bean Validation。
- 禁止拼接 SQL、动态执行、系统命令、不可信反序列化。
- 资金接口必须包含业务单号、幂等键、前后余额和审计记录。
- 所有业务查询都必须绑定认证上下文中的 `tenantId`。
- 时间以 UTC 存储和传输；界面按中国时区展示。

## 前端

- API 类型与 OpenAPI 同步；禁止在本地存储 openid、联盟密钥和租户选择结果。
- 页面必须覆盖加载、空数据、失败和成功反馈。
- 关键操作二次确认；导出和资金操作保留审计记录。

## 提交门禁

- 后端格式、单元测试、集成测试、依赖漏洞扫描通过。
- 管理端类型检查、Lint、构建和依赖审计通过。
- 数据库变化只通过 Flyway，禁止应用启动动态建表。
