# 产品需求说明

## 目标
交付一个支持平台管理员、租户管理员和微信用户的外卖 CPS 可运营 MVP。

## 范围
美团、饿了么官方联盟转链与订单同步；用户登录、直接邀请、订单、收益、钱包、人工提现；租户内容、渠道、PID、订单、分佣、提现和审计管理。

## 明确不做
自动转账、二级/团队/团长分佣、入门费与代理资格、淘宝联盟、旧数据自动迁移。奖励只来自真实已结算未退款订单。

## 退款与欠款规则
订单退款后优先扣回用户可用佣金，余额不足的部分进入欠款，不允许可提现余额为负。后续佣金先偿还欠款，剩余部分才可提现；存在欠款时暂停提交提现。所有变化必须保留原佣金记录并新增负向冲正和钱包流水。

## 关键指标
订单同步成功率、归因率、结算幂等率、钱包对账一致率、提现处理时长、跨租户访问拦截率。
