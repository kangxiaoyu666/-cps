# 安全威胁模型

| 威胁 | 控制 |
|---|---|
| 伪造 openid | 随机会话令牌，令牌散列保存，服务端解析用户 |
| 跨租户访问 | 认证上下文 tenantId、Repository 强制条件、自动化测试 |
| 重复结算/付款 | 唯一幂等键、行锁、乐观锁、状态条件更新 |
| 联盟响应篡改 | HTTPS、官方签名验证、契约测试、脱敏快照 |
| 管理员劫持 | HttpOnly/Secure/SameSite Cookie、CSRF、限流、BCrypt |
| 密钥泄漏 | 环境变量/KMS、应用层加密、日志脱敏、轮换 |
| 资金不一致 | InnoDB 事务、不可变流水、前后余额、每日对账 |
| CSV 滥用 | 最大行数、异步任务、权限校验、审计、水印 |

上线前执行 SAST、依赖扫描、渗透测试、租户隔离测试和资金并发测试。
